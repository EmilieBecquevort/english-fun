🌐 Listes partagées avec un Google Sheet

Avec un Google Sheet, plusieurs personnes peuvent ajouter ou corriger des mots, chacune sur son ordinateur. L’application lit le Google Sheet à chaque ouverture : Lucas a toujours la dernière version.

  1. Crée un Google Sheet avec deux onglets nommés exactement vocabulaire et conjugaison.
  2. Onglet vocabulaire : colonnes theme, anglais, francais. Onglet conjugaison : verbe, temps, sujet, affirmatif, negatif, interrogatif. (Astuce : exporte tes listes actuelles en CSV et importe-les dans chaque onglet.)
  3. Clique sur Partager → « Accès général » : Tous les utilisateurs disposant du lien (rôle Lecteur). Donne le rôle Éditeur aux personnes qui ajoutent des mots.
  4. Copie le lien du Google Sheet et colle-le ci-dessous.
  5. Clique sur « 📤 Créer la version pour Lucas » (plus bas) une seule fois pour que son application connaisse le lien.

Test rapide : ouvre ce lien de test dans une fenêtre de navigation privée. Si tu vois (ou télécharges) tes mots, le partage est bon. Si Google demande de se connecter, le Google Sheet n’est pas partagé avec « Tous les utilisateurs disposant du lien ».

📤 Envoyer les listes à Lucas

Les listes sont enregistrées uniquement dans le navigateur de cet appareil. Pour que Lucas les retrouve sur son appareil, crée une version de l’application qui contient tes listes, puis mets ce fichier à la place de l’ancien derrière le lien (ou envoie-le-lui).

Avec un Google Sheet : à faire une seule fois (le fichier contient le lien du Google Sheet). Sans Google Sheet : à refaire à chaque fois que tu changes les listes. À l’ouverture du nouveau fichier, les listes de Lucas sont remplacées par les tiennes. Ses erreurs à revoir sont conservées.

💾 Sauvegarde automatique

Les listes chargées sont enregistrées automatiquement dans ce navigateur. Lorsque tu rouvres cette application dans le même navigateur, elles sont normalement retrouvées.

Sauvegarde automatique activée

Important : garde aussi tes fichiers CSV comme copie de sécurité. La sauvegarde du navigateur peut être effacée si ses données sont supprimées ou si tu utilises un autre navigateur ou appareil.

📘 Charger une liste de vocabulaire

Le fichier CSV doit contenir trois colonnes : theme;anglais;francais.

📗 Charger une liste de conjugaison

Le fichier CSV doit contenir six colonnes : verbe;temps;sujet;affirmatif;negatif;interrogatif.

📊 Listes actuellement chargées

Les listes sont sauvegardées dès que le chargement réussit. Pour voir, corriger ou supprimer des mots, va dans « ✏️ Voir et modifier les listes ».
